{# Markdown editor for a description. nldd-text-editor is headless, so the formatting bar is ours: a toolbar of segmented controls, toggles and a text-style menu, wired both ways by text_editor.js (the controls run the editor's commands, its state event sets what reads as active). Every item has a twin in its overflow slot, for when the bar runs out of width in a narrow sheet. syntax="hidden": the marks only show where the caret is, so the text reads as formatted while the value stays Markdown. Form-associated: the value reaches the form natively. nldd-form-field sets input-id/accessible-label; the inline-edit field brings its own label. #}
