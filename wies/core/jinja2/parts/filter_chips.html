{# The active-filter chip strip: one removable nldd-token per active filter, plus a "Wis alle filters" button. Shared by every filtered list — the bezetting timeline, the users list, and the opdracht card/table containers. The token markup carries no URL: removal is declarative. Each token has data-wies-dismiss="filter" + data-filter-name/data-filter-value, and the clear-all button carries data-clear-all-filters; static/js/filter_interactions.js handles both. Keep those hooks in step with that file. Inputs: - filter_groups — list of {type, name, label, options}; select-multi and date groups produce chips here. - active_filters — {param_name: iterable_of_selected_values}. - org_chip_data — org-facet chips (only the PublicIdFacetsMixin pages pass these); each {param_name, param_value, label}. - unknown_chip_data — fail-closed "Onbekend" chips, same shape. The caller keeps the `{% if has_active_filters %}` guard and the trailing spacer: the guard expression and the spacer size differ per page.
